## About

**DevGame Store** is a dark-themed storefront landing page for gamers and developers — monitors, mechanical keyboards, headsets, controllers, and games, all in one place. It features a live product filter, instant search, and a dynamic masonry gallery, built entirely with vanilla JavaScript — no frameworks, no dependencies.

<br>

## Features

| | Feature | Description |
|---|---|---|
| 🎯 | **Category Filtering** | Instantly filter products by category — Monitor, Keyboard, Video Games, Headset, Controller |
| 🔍 | **Live Search** | Real-time product search that updates results as you type |
| 🖼️ | **Masonry Gallery** | Custom-built grid layout that sizes each image by its natural aspect ratio |
| 🔀 | **Randomized Catalog** | Product order shuffles on every page load for a fresh browsing experience |
| 📂 | **Dropdown Navigation** | Click-to-toggle category dropdown with outside-click detection |
| 🎨 | **Custom Dark Theme** | Maroon & cream palette with soft radial-gradient accents |
| 📱 | **Responsive Layout** | Adapts gracefully across desktop and mobile viewports |

<br>

## Tech Stack

| Layer | Technology |

## Getting Started

This is a fully static project — no build step required.

```bash
git clone https://github.com/Naznighty/devgame-store.git
cd devgame-store
```

Then just open `index.html` in your browser, or serve it with a live server (e.g. the VS Code Live Server extension).
