# 🧮 Calculator

یک ماشین‌حساب ساده و شیک با طراحی الهام‌گرفته از ماشین‌حساب macOS، ساخته‌شده با HTML، CSS و JavaScript خالص (Vanilla JS) بدون هیچ framework یا کتابخانه‌ای.

## ✨ ویژگی‌ها

- چهار عملیات پایه: جمع، تفریق، ضرب، تقسیم
- عملگر درصد (`%`)
- تغییر علامت عدد با دکمهٔ `+/-`
- پاک کردن کامل با `AC`
- حذف آخرین رقم با دکمهٔ Backspace (`⌫`)
- جلوگیری از وارد کردن چند نقطهٔ اعشار پشت‌سرهم
- کنترل خطای تقسیم بر صفر
- زنجیره کردن عملیات (مثلاً `5 + 3 × 2` بدون نیاز به زدن `=` بین هر مرحله)
- طراحی تیره با دکمه‌های گرد و رنگ‌بندی مشابه ماشین‌حساب macOS

## 🖥️ دمو

برای مشاهدهٔ پروژه، فایل `index.html` را در مرورگر باز کنید یا در صورت فعال بودن GitHub Pages، از لینک زیر استفاده کنید:

```

```

## 🚀 نحوهٔ اجرا

1. ریپازیتوری را کلون کنید:
   ```bash
   git clone https://github.com/<username>/<repo-name>.git
   ```
2. وارد پوشهٔ پروژه شوید:
   ```bash
   cd calculator
   ```
3. فایل `index.html` را در مرورگر باز کنید — نیازی به نصب یا سرور خاصی نیست.

## 🛠️ تکنولوژی‌های استفاده‌شده

| تکنولوژی | کاربرد |
|---|---|
| HTML5 | ساختار صفحه و دکمه‌ها |
| CSS3 | طراحی ظاهری، گرید دکمه‌ها، رنگ‌بندی |
| JavaScript (ES6) | منطق محاسبات و مدیریت رویدادها |

## 🎨 پیش‌نمایش رابط کاربری

طراحی شامل موارد زیر است:

- صفحه‌نمایش شفاف روی پس‌زمینهٔ تیرهٔ گرد
- دکمه‌های عددی خاکستری تیره
- دکمه‌های عملگر (`÷ × − +`) نارنجی
- دکمه‌های عملکردی (`AC`, `⌫`, `%`) خاکستری روشن

## 🧠 منطق برنامه (خلاصه)

برنامه با استفاده از سه متغیر اصلی کار می‌کند:

- `firstNumber` — عدد اول وارد‌شده
- `operator` — عملگر انتخاب‌شده
- `secondNumber` — عدد دوم وارد‌شده

با هر بار کلیک روی یک عملگر، اگر عدد دوم از قبل وارد شده باشد، ابتدا نتیجهٔ عملیات قبلی محاسبه شده و به‌عنوان عدد اول جدید در نظر گرفته می‌شود (امکان زنجیره کردن عملیات).
