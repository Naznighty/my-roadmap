# 🌿 GreenLeaf Home Services

A clean, responsive landing page for a fictional home services company offering house cleaning, laundry pickup, garden care, and grocery errands.

**Live Demo:** [https://naznighty.github.io/greenleaf/](https://naznighty.github.io/greenleaf/)

---

## 📋 About

GreenLeaf is a single-page website built to practice core HTML and CSS skills, including responsive layout, flexbox/grid, and a pure-CSS dark mode toggle (no JavaScript required).

## ✨ Features

- **Responsive navigation** with a collapsible mobile menu
- **Dark mode toggle** built entirely with CSS (`:has()` selector + checkbox hack)
- **Services section** with hover-animated cards
- **Image gallery** showcasing services
- **Contact form** with name, email, service selection, and message fields
- Fully responsive layout for mobile, tablet, and desktop screens

## 🛠️ Built With

- **HTML5** – semantic page structure
- **CSS3** – flexbox, grid, custom properties (CSS variables), media queries, and the modern `:has()` selector for dark mode

## 🚀 Getting Started

No build tools or dependencies required.

1. Clone the repository:
   ```bash
   git clone https://github.com/Naznighty/greenleaf.git
   ```
2. Open `index.html` in your browser.

That's it — the site runs entirely on static HTML and CSS.

## 🌗 Dark Mode

Click the toggle switch in the header to switch between light and dark themes. The theme is applied instantly using CSS custom properties, with no page reload or JavaScript involved.

## 📱 Responsive Design

The layout adapts at key breakpoints:
- **≤ 700px** – navigation collapses into a mobile-friendly menu
- **≤ 600px** – gallery grid switches from 3 columns to 2
